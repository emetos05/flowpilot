# FlowPilot agent instructions

Before making changes:

1. Read docs/ROADMAP.md.
2. Read docs/CURRENT_STATUS.md.
3. Inspect the existing implementation.
4. Work only on the currently approved day.
5. Do not begin the next day until every acceptance criterion passes.
6. Run and verify the affected application.
7. Update docs/CURRENT_STATUS.md after completing work.
8. Summarize files changed, commands run, tests performed, decisions and blockers.
